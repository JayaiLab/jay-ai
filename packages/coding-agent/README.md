# @jay-ai/coding-agent

[![npm](https://img.shields.io/npm/v/@jay-ai/coding-agent)](https://www.npmjs.com/package/@jay-ai/coding-agent)

A minimalistic CLI coding agent powered by jay-ai.

## Installation

```bash
npm install -g @jay-ai/coding-agent
```

## Usage

```bash
jayai
```

## Requirements

Node.js >= 24
