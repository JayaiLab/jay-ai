# @jay-ai/core

[![npm](https://img.shields.io/npm/v/@jay-ai/core)](https://www.npmjs.com/package/@jay-ai/core)

Core primitives for the jay-ai framework: LLM providers, event streaming, and shared types.

## Installation

```bash
npm install @jay-ai/core
```

## What's included

- **Providers** — Anthropic and OpenAI provider adapters
- **Event stream** — Unified streaming interface across providers
- **Types** — Shared message, model, and OAuth types

## Usage

```ts
import { AnthropicProvider, OpenAIProvider } from "@jay-ai/core";
```

## Requirements

Node.js >= 20
